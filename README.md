# Book Palette

## 1. アプリケーション概要

Book Paletteは、ユーザー同士でおすすめの本を紹介・共有できるWebアプリケーションです。

会員登録・ログインを行い、おすすめしたい本の情報や感想を登録できます。また、他のユーザーが紹介した本の閲覧や検索もできます。

## 2. 使用技術・開発環境

| 項目 | バージョン・環境 |
|---|---|
| OS | Windows |
| エディタ | Visual Studio Code |
| Python | 3.13.5 |
| Flask | 3.1.0 |
| MySQL Server | 9.3.0 |
| mysql-connector-python | 26.10.0 |
| SQL管理ツール | A5:SQL Mk-2 |

## 3. 主な機能

- 会員登録・ログイン
- おすすめ本の登録
- 登録した本の編集・削除
- 本の検索
- 本の詳細情報の表示
- 他のユーザーのおすすめ本の閲覧
- マイページ
- ログアウト

## 5. セットアップ手順

### 5-1. 必要なソフトウェア

以下のソフトウェアを事前にインストールしてください。

- Python 3.13.5
- MySQL Server 9.3.0
- Visual Studio Code
- A5:SQL Mk-2

### 5-2. ソースコードの取得

GitHubからリポジトリをクローンするか、ZIP形式でダウンロードします。

### 5-3. Pythonライブラリのインストール

Visual Studio Codeでプロジェクトを開き、ターミナルを起動します。

以下のコマンドを実行します。

```bash
python -m pip install Flask==3.1.0
python -m pip install mysql-connector-python==26.10.0
```

### 5-4. データベースの作成

MySQL Serverを起動し、A5:SQL Mk-2からMySQLに接続します。

プロジェクト直下にある `DB設計.sql` を開き、SQLを実行します。

実行後、以下のデータベースとテーブルが作成されます。

- データベース：book_app
- テーブル：users
- テーブル：books

### 5-5. データベース接続設定

データベースへの接続情報は、利用するMySQL環境に合わせて設定します。

※詳細な接続設定については確認後に追記します。

### 5-6. アプリケーションの起動

Visual Studio Codeのターミナルで、以下のコマンドを実行します。

```powershell
cd .\IH12A203-23-堀綾花
python app.py
```

### 5-7. ブラウザでアクセス

アプリケーション起動後、ブラウザで以下のURLを開きます。

http://127.0.0.1:5000/

## 6. データベース構成

本アプリケーションでは、MySQLを使用して会員情報と本の情報を管理しています。

### usersテーブル

会員のユーザー名、メールアドレス、パスワードを管理します。

### booksテーブル

本のタイトル、著者、ジャンル、本の種類、表紙画像、概要、おすすめコメントを管理します。
